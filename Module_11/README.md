# Описание задания "Лидарная навигация"
1. Конвертируйте данные в формат xyz (для использования kiss icp)
2. Запустите скрипт для конвертации python3 laz_to_xyz.py /path/in/ дождитесь результата
в папке /path/in/xyz рядом с исходными данными должны появиться файлы в формате xyz
3. Устновите зависимость pip install "kiss-icp[all]"
4. Запустите kiss_icp kiss_icp_pipeline /path/in/xyz -v
5. В текущей директории появится файл с отписанной траекторией движения 
6. Запустите скрипт python3 map_builder.py ..../xyz .../xyz_poses.npy
7. Посмотрите какие ошибки есть при формировании карты (стабилен ли уровень земли) устраните их
и сохраните в любом формате, далее откройте в стороннем редакторе и пришлите изображение карты в отчете
